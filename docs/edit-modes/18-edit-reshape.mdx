# Reshape Mode

:::info Pro feature
Reshape Mode is part of the polygon sub-editing suite and is only available in **MapLibre-Geoman Pro**.
:::

Draw a line that replaces a run of the selected polygon's boundary, growing or shrinking it — the QGIS "Reshape Features" tool. Draw a line across the boundary (click to place each vertex); **right-click cancels** an in-progress line.

You can handle Reshape Mode for all layers on a map like this:

```js
map.gm.enableMode('edit', 'reshape');
map.gm.disableMode('edit', 'reshape');
map.gm.toggleMode('edit', 'reshape');
map.gm.isModeEnabled('edit', 'reshape');
```

The following methods are available on `map.gm`:

| Method                               | Returns   | Description                                                            |
|:-------------------------------------|:----------|:----------------------------------------------------------------------|
| `enableMode('edit', 'reshape')`      | -         | Enables global Reshape Mode.                                          |
| `disableMode('edit', 'reshape')`     | -         | Disables global Reshape Mode.                                         |
| `toggleMode('edit', 'reshape')`      | -         | Toggles global Reshape Mode.                                          |
| `isModeEnabled('edit', 'reshape')`   | `Boolean` | Returns `true` if global Reshape Mode is enabled. `false` when disabled. |

## Selection requirement

Reshape is scoped to the **selected parent polygon** — the drawn line is applied to the selected feature. Select a polygon first via [Select Mode](./12-edit-select.mdx) or `geoman.features.setSelection([id])`.

## Events

Reshape does not emit per-mode start/end events. It uses the standard edit/feature events for success, and `gm:operation_rejected` when the line cannot be applied:

| Event                            | Params  | Description                                                  | Output                              |
| :------------------------------- | :------ | :---------------------------------------------------------- | :---------------------------------- |
| `gm:reshape`                     | `event` | Fired when the boundary is reshaped (feature updated).      | `map`, `feature`, `originalFeature` |
| `gm:operation_rejected`          | `event` | Fired when the drawn line is rejected (no geometry change). | `map`, `mode`, `reason`, `feature`  |
| `gm:globalreshapemodetoggled`    | `event` | Fired when Reshape Mode is toggled.                        | `enabled`, `map`                    |

For Reshape the `gm:operation_rejected` `reason` is `no_target` (no selected polygon to reshape) or `invalid_geometry` (the drawn line does not produce a usable reshape).

```js
map.on('gm:operation_rejected', (event) => {
  if (event.mode === 'reshape') {
    showToast(`Could not reshape: ${event.reason}`);
  }
});

map.on('gm:globalreshapemodetoggled', (event) => {
  console.log(event.enabled);
});
```

## Behavior

The drawn line replaces the run of the selected polygon's boundary between the points where the line meets it, so a line drawn outside the boundary grows the polygon and a line drawn inside shrinks it. The mode operates on the selected `Polygon`/`MultiPolygon`; if the line does not produce a valid reshape the operation is rejected and the geometry is left unchanged.

## Programmatic API

The same operation is available without the toolbar via the `geoman.edit` façade, driving the edit by feature id:

```js
const result = await geoman.edit.reshape(featureId, line); // line: Position[]
if (!result.ok) showToast(result.reason); // 'no_target' | 'invalid_geometry'
```
